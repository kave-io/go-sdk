# Kave Go SDK V2

The V2 SDK scopes OpenAI-compatible HTTP calls to a static Kave agent. It does
not accept provider credentials and does not retry requests.

Provision static routes and agents once with an admin service key. Pricing is
integer nano-USD per million tokens and must receive a new revision whenever a
rate changes:

```go
_, err := client.Apply(ctx, kave.Manifest{
	Namespace: kave.Namespace{
		Account: "account/acme", Application: "simorq", Environment: "production",
	},
	Routes: []kave.Route{{
		Name: "openai", Provider: "openai", Secret: "openai",
		AllowedModels: []string{"example-model"}, DefaultModel: "example-model",
		PricingRevision: 1,
		Pricing: []kave.ModelPrice{{
			Model: "example-model", // use your provider's versioned price sheet
			InputNanosPerMillionTokens:  250_000_000,
			OutputNanosPerMillionTokens: 2_000_000_000,
		}},
	}},
	Agents: []kave.AgentSpec{{
		Name: "clinic-assistant", Kind: kave.AgentLLM, Route: "openai", Enabled: true,
	}},
}, kave.Once("deploy/2026-07-18"))
```

The referenced provider secret is written separately with
`PutEncryptedSecret`; secret values never enter a manifest. Dynamic clinic or
subscription limits should be published after the application transaction
with `SyncLimits`, using the application outbox revision and event ID.

Set `KAVE_URL` and `KAVE_SERVICE_KEY`, then create a scoped client. The service
key fixes the namespace; callers cannot override it with headers:

```go
client, err := kave.OpenFromEnv()
if err != nil {
	return err
}

ctx = kave.WithScope(ctx, kave.Scope{
	Tenant:  kave.Ref("clinic/" + clinicRef),
	Actor:   kave.Ref("user/" + actorRef),
	BillTo:  kave.Ref("clinic/" + clinicRef),
	Session: kave.Ref(runRef),
})
ctx = kave.WithInvocation(ctx, kave.Once(stepRef))

req, err := http.NewRequestWithContext(ctx, http.MethodPost,
	"https://api.openai.com/v1/responses",
	strings.NewReader(`{"model":"gpt-5","input":"hello"}`),
)
if err != nil {
	return err
}

resp, err := client.HTTPClient(kave.Agent("clinic-assistant")).Do(req)
```

Consume a product quota exactly once before starting a retryable workflow:

```go
decision, err := client.Consume(
	ctx,
	kave.Agent("clinic-assistant"),
	kave.Metric("ai_actions"),
	1,
	kave.Once(runRef),
)
if errors.Is(err, kave.ErrLimitExceeded) {
	var exceeded *kave.LimitExceededError
	if errors.As(err, &exceeded) {
		// exceeded.Decision.Violations is structured limit data.
	}
}
```

`Once` is a required argument rather than an optional convention. Repeating an
identical request returns the original decision with `Replayed` set; reusing
its key for different input is rejected by Kave.

The transport accepts only `POST /v1/responses`, `POST /v1/chat/completions`,
and `POST /v1/embeddings`. It sends them to the configured Kave origin under
`/v2/agents/{agent}/openai/*`, replaces `Authorization` with the Kave service
key, attaches only pseudonymous scope plus the stable invocation identity, and
refuses redirects. Query parameters, cookies, baggage, caller credentials, and
all non-allowlisted headers are rejected or removed before transport.

Service-key raw material is generated by the SDK. Only its random lookup prefix
and SHA-256 verifier cross the control API, so the server cannot recover or
return the credential. `IssueServiceKey` returns the locally held `RawKey` for
both creation and an idempotent replay. If transport fails after a possibly
committed request, the returned partial result still contains `RawKey`; set it
on `ServiceKeySpec.RawKey` when retrying with the same idempotency key. Supplying
different material for that key is rejected rather than silently rotating it.

`RevokeServiceKey` and `RevokeSecret` are typed, idempotent SDK operations.
Both validate identifiers and single-line audit reasons before sending a
request.

Usage returned by `QueryUsage` carries `Estimated=true` when Kave had to settle
an uncertain or abandoned provider attempt conservatively instead of receiving
trustworthy provider-reported usage. Keep those entries in billing totals, but
surface the marker in reconciliation and operator reports.
